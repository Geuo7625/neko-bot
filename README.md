# 🐾 QQ AI Bot

一个面向 QQ 与 Telegram 的 AI Bot 项目。

它可以聊天、搜索资料、理解图片，也可以生成图片和视频，还支持 Markdown、LaTeX、Mermaid、代码等内容的处理与渲染。

让 AI 不只是会聊天，还能真正做一些事情 ฅ^•ﻌ•^ฅ

## ✨ 功能

### 💬 AI 对话

- 支持自然语言对话
- 支持群聊与私聊
- 支持上下文记忆
- 支持流式回复
- 支持复杂问题的分析与思考

### 🔎 联网搜索

- 支持联网搜索
- 获取实时网络信息
- 可用于资料查询、新闻检索、知识搜索等

### 👀 图片理解

- 支持理解用户发送的图片
- 可以结合图片内容进行对话
- 支持多模态交互

### 🎨 AI 图片生成

- 根据文字描述生成图片
- 支持编辑最近生成的图片
- 支持不同图片比例
- 支持异步生成

### 🎬 AI 视频生成

- 支持根据提示生成视频
- 支持异步视频生成
- 自动处理生成结果

### 📐 内容渲染

对于 QQ、Telegram 中不太方便直接展示的内容，可以进行渲染处理：

- Markdown
- LaTeX / 数学公式
- Mermaid 图表
- 代码
- 其他特殊格式内容

让复杂内容也可以更舒服地展示出来 ✨

### 🐾 平台交互

#### QQ

基于 [NapCat](https://github.com/NapNeko/NapCatQQ) 构建 QQ 端能力，支持：

- 群聊
- 私聊
- @ 用户
- 戳一戳
- 图片
- 视频
- 引用消息
- 历史消息

#### Telegram

同时提供 Telegram 平台支持，可以在 Telegram 中使用 AI 对话及相关能力。

### 🧰 AI 工具调用

AI 可以根据当前对话选择合适的工具，例如：

- 🔎 联网搜索
- 🎨 图片生成
- 🎬 视频生成
- 👥 平台交互

让 AI 从单纯的「回复消息」变成可以完成任务的小助手。

### ⚡ 异步任务

图片、视频等耗时操作会进行异步处理，避免长时间运行的任务影响正常聊天。

## 🛠️ 技术栈

- Node.js
- NapCat
- Telegram
- WebSocket
- SSE
- AI API
- Docker
- Playwright / Chromium

## 🌱 项目简介

这是一个用于探索 **AI + Bot + Agent** 的开源项目。

项目希望将 AI 的对话、多模态理解、联网搜索、内容生成以及工具调用能力，带到 QQ 和 Telegram 等聊天平台中。

它还在不断成长中，功能和架构也会持续改进。
